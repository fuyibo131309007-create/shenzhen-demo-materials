# GPM（增长产品经理）岗位 JD

## 岗位基本信息

- **岗位名称：** 增长产品经理（GPM）
- **工作地点：** 某市
- **汇报对象：** 产品总监
- **HC 方向：** PLG 全链路增长 / 商业化定价 / 开发者生态（第二 HC）

---

## 岗位职责

1. **PLG 增长全链路负责：** 负责 PLG 产品从获客、激活、留存到付费转化的完整增长链路，制定并执行增长策略，驱动核心指标持续提升
2. **实验体系搭建与运营：** 搭建和优化 AB 实验体系，设计实验方案、分析实验结果，通过数据驱动产品决策和迭代
3. **商业化与定价优化：** 主导付费转化、定价策略、套餐设计等商业化项目，提升 ARPU 和付费转化率
4. **用户行为分析：** 深度分析用户行为数据，识别增长机会点和流失原因，输出可落地的增长方案
5. **跨团队协作：** 与产品、研发、数据、设计、运营团队紧密协作，推动增长项目从方案到落地全流程闭环

---

## 任职要求（硬性条件）

| 维度 | 要求 |
|---|---|
| **学历背景** | 本科及以上学历 |
| **工作年限** | 3~5 年以上互联网产品经理经验，产品 title 满 2 年 |
| **产品方向** | 有 PLG / SaaS / B 端产品经验 |
| **数据能力** | 熟练使用 SQL 进行数据提取和实验分析，掌握 Python 优先 |
| **实验经验** | 有独立 AB 实验设计经验，熟悉样本量估算、统计显著性判断 |
| **体系经验** | 有实验体系或指标体系搭建经验 |
| **职业稳定性** | 近 3 年无频繁跳槽（单份工作不满 1 年的不超过 1 次），无长期职业空窗 |
| **到岗要求** | 可到岗本地坐班，不接受纯远程/异地 |
| **项目量级** | 负责过的产品 DAU > 1 万以上 |
| **合规要求** | 无不可接受的竞业限制风险 |

---

## 加分项（优先考虑）

1. **PLG 全链路操盘经验：** 完整负责过从获客、激活到付费转化的 PLG 增长闭环
2. **商业化/定价经验：** 主导过定价改版、套餐设计、付费转化率提升等商业化项目
3. **实验体系从 0 到 1：** 从零搭建过公司级或业务线级的 AB 实验平台和实验规范
4. **开发者生态方向：** 有开发者平台、API 产品、开发者增长相关经验
5. **自助试用链路：** 有 Free Trial / Freemium 模式下的试用转化链路优化经验
6. **数据分析平台背景：** 有数据产品或分析平台相关背景，数据敏感度高

## 面试评估维度

候选人将从以下 5 个维度进行评估分级：

| 维度 | 评估重点 |
|---|---|
| **岗位匹配度** | PLG / 商业化 / 实验体系等核心要求的匹配程度 |
| **关键项目相关性** | 过往项目与本岗位业务场景的相似度和成果量级 |
| **行业经验** | SaaS / B 端 / 开发者生态等行业背景的对口程度 |
| **稳定性风险** | 职业轨迹、跳槽频率、到岗周期、薪资匹配度 |
| **沟通风险** | 表达逻辑、数据敏感度、协作沟通能力 |

## 初筛筛选规则

### 硬性条件淘汰规则
- 不满足上述硬性条件任意一条的候选人，默认不进入短名单
- 淘汰时必须记录具体淘汰理由和硬性条件缺口

### A/B/C 推荐等级标准
- **A 级（强匹配）：** 核心要求全部满足，且在 PLG 全链路 / 商业化 / 实验体系等关键方向有突出成果，即插即用
- **B 级（匹配良好）：** 硬性条件全部满足，核心方向基本匹配，有一定经验但深度或广度略有欠缺
- **C 级（基本满足）：** 满足硬性条件，但方向相关性一般，行业迁移成本较高，可作为储备人选

### 短名单要求
- 短名单人数控制在 5 人以内
- 每位短名单候选人需给出建议面试轮次和建议面试官角色
- 重点候选人需同步标注风险项和下一步动作
