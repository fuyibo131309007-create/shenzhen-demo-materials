# 排序规则（RICE + 基础可用性门槛）

> 本包演示数据为现场合成，仅用于现场 Workshop，不代表真实经营数据。

演示主体：示例企业A 一类工业建模/仿真产品团队。

## RICE
- Reach：一季可触达用户数（用反馈去重会话/账号估）  
- Impact：对核心任务的影响 0.25/0.5/1/2/3  
- Confidence：高 100% / 中 80% / 低 50%（无证据偏低）  
- Effort：人月  

Score = R×I×C / E

## 基础可用性门槛（不过门槛不进版本）
1. 无阻断级安全问题  
2. 有可观察验收标准  
3. 不依赖未排期外部 DEP（或已解依赖）  
4. Wish 不得仅凭单条反馈进 Must

## 版本建议写法
Must / Should / Could / Won't(本季)；每条回溯反馈ID与缺陷ID。

## 现场使用注意
- 本文件为业务输入，不是答案；请独立生成后再与沉淀产物对照。
- 涉及金额、编制、客户名均为演示假设，禁止对外当作真实承诺。
- 关联时优先用表内 ID；缺字段写「待确认」，禁止填 0 冒充。
