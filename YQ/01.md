# 舆情监控与管理 · 任务配置

> 说明：本文件为「舆情监控与管理」案例的演示输入材料，将监控任务配置结构化，供演示时作为输入依据（对应案例提示词，见 01_提示词/现场一句话.txt）。

## 一、监控主题

消费健康（"消费健康"舆情池）

## 二、监控平台（每天定时巡检）

| 平台 | 说明 |
| --- | --- |
| 微博 | 综合舆情主阵地，覆盖话题/热搜 |
| 微信公众号 | 深度文章与行业观点 |
| 小红书 | 用户真实反馈与种草笔记 |
| 抖音 | 短视频舆情与评论区 |
| 知乎 | 专业讨论与问答 |

## 三、监控关键词

- 保健食品
- 功能性食品
- 健康零食
- 营养补剂
- 无糖饮品
- 食品安全

## 四、筛选规则

- 时间窗口：过去 24 小时（每天巡检时取前一天内容）
- 热度筛选：高热度内容（互动量/阅读量达到阈值）或负面内容（涉及安全、虚假宣传、质量问题等）
- 情感分类：负面 🔴 / 动态 🔵 / 正面 🟢

## 五、输出看板与推送

- 整理为一个可视化看板（按情感分类聚合）
- 生成飞书卡片，推送到「舆情监控小组」群
- 推送时间：每天 11:00

## 六、卡片格式

标题：消费健康舆情日报 | {日期}

分类展示：
- 🔴 负面
- 🔵 动态
- 🟢 正面

每条内容：情绪 emoji + 一句话摘要 + 来源 + 链接
